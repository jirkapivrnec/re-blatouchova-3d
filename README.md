# re-blatouchova-3d

Blatouchová 1111, Obec — a house that builds itself as you scroll.

- `pudorys.json` – floor plan (cm) of both floors
- `blender/build_house.py` – parametric Blender model generated from the plan (315 parts)
- `web/` – React + three.js scroll page, see [web/README.md](web/README.md)
